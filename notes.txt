*********** WORKING PROCESS *****************
Phase 1:

- Create and Activate python environment
python3 -m venv env
linux : source env/bin/activate

- Install Django
pip3 install django , python-dotenv

- Create project and apps
cd resume_parser
django-server startproject resume_parser .

python3 manage.py startapp core

- Add core in settings.py

- Create templates folder and add a dummy html file 
- Go to core/ and create a file urls.py :

    path('' , include('core.urls'))

- In core/urls.py :
    urlpatterns = [
        path('',views.index,name = 'index')
    ]

- In views.py :
    def index(requests):
        return render(requests,'index.html')

- Adding static in django: (https://docs.djangoproject.com/en/2.2/howto/static-files/)
Goto settings.py:
    STATIC_URL = '/static/'

    if multiple directories
    STATICFILES_DIRS = [
        os.path.join(BASE_DIRS,"static"),
        
    ]

    MEDIA_URL = '/media/'
    MEDIA_ROOT = os.path.join(BASE_DIR, 'media')

Working:
User request(Browser) ----> Project's urls.py ------> app's urls.py ------> views.py (points to templates/index.html) -----> return templates ---> Browser

User submits cv ---> :formdata -> Fetch API -> method POST -> Server -> View -> Store cv

Phase 2: Database Connectivity
- pip install psycopg2-binary
- Create Database

In settings , replace database connectivity with:
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': 'resume_parser_db',
        'USER': 'your_postgres_username',
        'PASSWORD': 'your_postgres_password',
        'HOST': 'localhost',
        'PORT': '5432',
    }
}
